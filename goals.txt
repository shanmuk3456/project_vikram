# Things I Would Change Immediately

## Remove

Your parser currently does

```python
match = re.search(r'\{.*\}', response, re.DOTALL)
```

This is greedy.

Instead use a more reliable extraction approach or make the controller output cleaner. A greedy regex can accidentally consume extra braces if the model includes additional JSON-like text.

```python
requests.post(..., timeout=120)
```

## My Recommendation

If I were mentoring this project, I would **not** add ChromaDB, LangChain, or autonomous agents next.

I would prioritize them in this order:

1. Stabilize the current pipeline (logging, retries, validation, Ollama checks).
2. Support **multi-file project generation**.
3. Make the assistant **workspace-aware** (understand existing files and their relationships).
4. Add a **planner** that can break a request into multiple steps.
5. Only then add persistent memory and more advanced agent behavior.

At that point, you'll have a strong foundation that you can continue building without constantly fighting architectural problems. That foundation is what will make later features much easier to add.
